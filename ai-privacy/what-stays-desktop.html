What Stays on Your Computer After a Claude Code Session

Unknown unknown #4 — Claude Code writes a complete record of every session to a hidden folder on your computer, automatically and without prompting you. Most users don’t know it’s there.

Using the Terminal (CLI) instead? Read the Terminal version →

The last post described what happens on Anthropic’s side after a Claude Code session ends: what their servers receive, how long it’s retained under different account types, and what the terms of your data-processing agreement permit them to do with it. This post focuses on your side. After every Claude Code session, a copy of that session remains on your computer: created without a prompt, stored in a location most users have never navigated to, and kept for thirty days by default. A copy of the session will also get saved by Time Machine or a similar backup service, for as long as that backup exists.

What Claude Code stores, and where

Claude Code writes every session to a set of files inside a folder called .claude in your home directory. The period at the start of the name is key. On a Mac, folders whose names begin with a period are hidden from view by default. They do not appear in Finder when you browse normally. The folder is there; it’s just not shown.

Inside .claude, in a subfolder called projects, Claude Code stores your conversations as transcript files — one per session, containing the full exchange: your prompts, Claude’s responses, and the contents of any files Claude Code opened during the session. Written as a path, the location is:

~/.claude/projects/

By default, Claude Code retains these files on your computer for thirty days; it then deletes them automatically, without any notification to you.

What the transcript contains

The transcript is a complete record, not a summary or a curated version of the session. When you work with Claude Code, you are working through a problem: iterating, revising, pasting in context to give the tool enough to help you. The transcript captures all of it. If you opened a file containing identifiable student information, a research participant’s transcript, or budget details that were not meant to leave your office, that content is in the session transcript. It’s not there because you saved it, but simply as a byproduct of working with Claude Code.

The discovery problem

The access risk these files pose is not unique to Claude Code. Anyone who has access to your computer — an IT technician servicing it, a colleague borrowing it — can read them the same way they could read any file on your computer. But if you don’t know the transcripts are there, you can’t apply judgment about whether or not you want to save them. And you aren’t aware of the potential risk that someone else could see your transcripts if they gain access to your computer.

In addition to transcript files that are stored on your computer, if you back up your computer using Time Machine or a service that backs up your entire computer, those backups do not skip hidden folders. That means your session transcripts are included in your backups alongside your documents — and those backup copies may persist long after Claude Code’s automatic cleanup has removed them from your machine. So if you share your backup drive with someone, like an IT tech who’s repairing it, it carries those copies with it.

A note on which tool you’re using

This applies to Claude Code — specifically, the Code mode, whether you run it through the Claude desktop app or from a terminal window. Both write to the same ~/.claude/projects/ folder; although the interface is different, the storage behavior is the same.

If you use the Chat mode in the Claude desktop app, or Claude through a browser, there are no transcript sessions written to your machine. But Anthropic does still retain your data on its server side, as discussed in the previous post. Cowork mode is a separate case, which I’ll get to in a later post.

How to find and manage your transcripts

To see your transcripts in Finder, press Command + Shift + period. This makes hidden items visible. Your home directory will now show the .claude folder alongside your usual ones. Open it, open projects, and you’ll find one subfolder per project, each holding the session files from that work.

To remove transcripts, select and delete the files from Finder. Claude Code automatically deletes files older than thirty days, but that cleanup runs silently and does not apply to backup copies. If you want to manage what’s stored here on an ongoing basis, it is a manual step you should take periodically.

The takeaway

Claude Code writes a full transcript of every session to ~/.claude/projects/ on your computer — hidden by default, kept for thirty days, and included in backups.

  • To see what’s there: In Finder, press Command + Shift + period to show hidden folders. Navigate to .claude → projects.
  • To remove transcripts: Delete the files from Finder. Claude Code automatically removes them after thirty days, but that cleanup does not reach your backups.
  • On backups: Time Machine and similar backup services include hidden folders. Copies of your transcripts may already exist on backup drives — those need to be managed separately.
  • On which tool this applies to: Code mode (desktop app or terminal). Chat mode in a browser or the desktop app creates no local transcript.
